# Keyword Research Template

Import `keyword-research-template.csv` into Google Sheets or Excel.

## Columns
- **Keyword:** the search phrase
- **Monthly Volume / Difficulty:** from your keyword tool
- **Search Intent:** Informational, Commercial, Transactional or Navigational
- **Target Page URL:** the one page that should rank for it
- **Current Position:** from Search Console
- **Priority:** High, Medium or Low

## Tip
Give each keyword one target page. If two pages target the same keyword, merge them or change one.

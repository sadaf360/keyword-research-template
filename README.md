## 🚀 How to Use

1. Download the file → [`keyword-research-template.csv`](https://github.com/sadaf360/keyword-research-template/raw/main/keyword-research-template.csv)
2. Open it in **Google Sheets** or **Excel**
3. Fill the columns while doing keyword research
4. Use filters & conditional formatting for better visibility

---

## 📋 Columns Explained

| Column | What to put |
|--------|-------------|
| **Keyword** | The exact search phrase |
| **Monthly Volume** | Search volume from your tool (Ahrefs / Semrush / Keyword Planner) |
| **Difficulty** | KD score (0–100) |
| **Search Intent** | Informational / Commercial / Transactional / Navigational |
| **Target Page URL** | The one page that should rank for this keyword |
| **Current Position** | Current ranking from Google Search Console |
| **Priority** | High / Medium / Low |

---

## 💡 Best Practices

- **One keyword = One target page**  
  If two pages target the same keyword → merge them or change the focus of one.
- Group keywords by **topic clusters**
- Always check **search intent** before creating content
- Update the "Current Position" column every month
